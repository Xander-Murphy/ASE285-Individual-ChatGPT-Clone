# AI chat Manuel

- visit https://groq.com/
- press developers > free API key > create account with email
- Click link in your email
- create API key, SAVE THIS SOMEWHERE
- Create a .env file in the root

---
# Manuel Page 2
paste this into your .env file
``` 
GROQ_API_KEY=YOUR_KEY_HERE
PORT=5000
```

- run `npm run dev` or `npm run electron:dev` in the directory
- Ask questions make or delete chats!
