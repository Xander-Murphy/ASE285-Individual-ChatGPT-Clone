# Frontend Requirements

## Features
1. Chat centered user interactions — message input, send button, Enter key support
2. Multiple conversations — sidebar for creating, switching, and deleting named conversations
3. Conversation history — full message history displayed per conversation
4. Real-time streaming — assistant responses stream token by token into the message bubble
5. Markdown rendering — assistant messages rendered with ReactMarkdown
6. Custom modal — in-app dialog for naming new conversations (replaces browser prompt)
